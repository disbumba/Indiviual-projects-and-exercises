## How to run
### C++ (Visual Studio)
1. Open the `.sln` file from the project folder.
2. Select `Debug` or `Release`.
3. Run using `Local Windows Debugger`.

### Web
1. Go to the `Programare_WEB/` folder.
2. Open `index.html` in a browser  
   or use a local server (e.g., VS Code Live Server).
